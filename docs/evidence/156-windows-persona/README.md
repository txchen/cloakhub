# 156 Windows persona evidence

See [the report](../../156-windows-persona.md). These observations were generated by
`tests/browser-evaluation/run.mjs` while introducing the reusable suite.

- `system-fonts/`: 3 seeds × 2 modes × 2 rounds = 12 profiles; Windows persona,
  system fontconfig, official 156 binary, only Fingerprint as an external detector.
- `mac-font-control/`: same image and seed 20260909, 2 modes, explicit Mac fontconfig
  as a sensitivity control. This is not a recommended Windows environment.
- `macos-suite-smoke/`: one subsequent headed macOS adapter check, with all four
  detector adapters complete. Fingerprint VM/tampering/anti-detect were false;
  preserve this differing observation rather than silently treating old VM results
  as immutable version properties. Its suite build and timestamp differ from the
  Windows groups; it is not a strict single-variable persona comparison.
- Each directory contains the runner's manifest, results, summary and Markdown
  report, plus the actual evaluation-image ID in `provenance.json`.
- The two Windows groups used the same image. The subsequently finalized suite adds source
  hashing, stronger owned-process cleanup, webdriver capture and expanded report
  tables; the recorded verdicts were not rewritten to pretend those additions ran.
- No raw license key, visitor/event ID, external IP, full page text, cookie or
  screenshots are included. Actual argv contains only owned temporary profile paths
  and a private ephemeral CDP-port setting.

The old report template is intentionally retained with these historical records.
Future runs use the current source under `tests/browser-evaluation/`, not a copied
historical harness. Missing/limited results are distinct from positive detections.

Validate recorded counts without network or browser access:

```sh
node docs/evidence/156-windows-persona/verify.mjs
```
