# Go Hub runtime

CloakHub's server is rewritten from TypeScript on Bun to Go: one static binary with the operator UI embedded, replacing the Bun runtime and its production dependencies. The goal is a small footprint for trial deployments: the Hub idles at about 15–20 MB of resident memory instead of about 70 MB, and the image loses the ~90 MB Bun runtime. HTTP routes, JSON shapes, error contracts, the SQLite schema and data directory layout stay compatible, so existing data directories and clients keep working; the UI remains TypeScript bundled by esbuild, and Bun stays a development tool for the browser skill, UI type checks and Playwright. The runtime browser installer (`CLOAKHUB_BROWSER_INSTALLER`) and license-key management (`CLOAKHUB_LICENSE_*`, per-key quotas and browser homes) are not carried over: the image bakes an unrestricted browser, source runs mount one, and CloakHub assumes the binary needs no license.
